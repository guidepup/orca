# Guidepup Orca

[Orca](https://gitlab.gnome.org/GNOME/orca) is a free, open source screen reader for Linux. It is part of the GNOME Project in collaboration with a global community of contributors. To learn more about Orca or download a copy, visit the main [Orca](https://orca.gnome.org/) website.

This repo hosts a built, portable copy of Orca, configured for optimal use with Guidepup.
